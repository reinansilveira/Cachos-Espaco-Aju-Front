# Fotos do salão

Fotos do post de inauguração do espaço novo no Instagram (@espacocachosaju),
redimensionadas para 1600px. Os nomes são usados em `src/salon/salon.data.ts`
(`PHOTOS`); para trocar uma foto, substitua o arquivo mantendo o nome.

| Arquivo                      | Onde aparece                            |
| ---------------------------- | --------------------------------------- |
| `fachada.jpg`                | Foto grande da seção "O espaço"         |
| `fachada-noite.jpg`          | Seção "Visite"                          |
| `recepcao.jpg`               | Espaço, serviços de cor e tela de login |
| `salao-recepcao-cadeira.jpg` | Serviços de tratamento                  |
| `salao-parede-verde.jpg`     | Serviços de corte                       |
| `salao-por-do-sol.jpg`       | Espaço e terapia capilar                |
| `estacao-make.jpg`           | Espaço e penteado/make                  |

Vídeos do tour pelo salão (enviados pelo salão em novembro de 2026), sem som,
no fundo do topo da home: `tour.mp4` (horizontal, computador) e
`tour-vertical.mp4` (celular). Os `*-poster.jpg` são o primeiro quadro de cada
um e aparecem enquanto o vídeo carrega. `salao-espelhos.jpg`,
`salao-lavatorio.jpg`, `salao-lavatorio-vertical.jpg` e `salao-espera.jpg` são
quadros dos vídeos.
