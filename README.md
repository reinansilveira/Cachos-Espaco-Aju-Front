# Espaço Cachos Aju — Front

Site e painel do salão Espaço Cachos Aju (Aracaju/SE): agendamento online, painel da dona e da equipe, estoque de produtos e comanda com Pix e cartão.

```bash
cp .env.example .env
npm install
npm run dev   # http://localhost:3011
```

A API (`cachos-espaco-aju-backend`) precisa estar rodando em `http://localhost:3010`. Mais detalhes em `CLAUDE.md`.
